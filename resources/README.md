# Companion Resources

Editable worksheets for the first five articles. These are reference methods, not completed audits or verified vendor import formats.

| Resource | Purpose |
|---|---|
| [Platform requirements](01-platform-requirements.md) | Define the evidence and workflow capabilities to evaluate. |
| [Recommendation-gap checklist](02-recommendation-gap-checklist.md) | Separate observed omissions, hypotheses, and next actions. |
| [Buyer-intent prompt CSV](03-prompt-set.csv) | Start a versioned question set with clearly labeled synthetic examples. |
| [Metric dictionary](04-metric-dictionary.md) | Keep observation units, denominators, and limitations explicit. |
| [Monitoring decision worksheet](05-monitoring-decision.md) | Estimate collection and review effort and choose an operating cadence. |

Replace synthetic prompts with approved questions before collecting a baseline. The CSV is UTF-8; its four rows are examples, not collected buyer data or assertions about a real product's capabilities.

Assign owners and define review statuses before using the worksheets. Keep confidential answers and source records in appropriate storage rather than publishing them with these templates.
