# Metric Dictionary

These are editorial reporting conventions. They do not specify a vendor's scoring implementation.

| Field or measure | Definition | Required caveat |
|---|---|---|
| Scheduled trials | All planned collection attempts | Preserve failed attempts |
| Completed scorable answers | Answers meeting the declared inclusion rule | State treatment of refusals |
| Mention rate | Answers mentioning the normalized entity / scorable answers | Not a recommendation measure |
| Owned-domain citation rate | Answers displaying a qualifying owned-domain citation / scorable answers | Not claim-support accuracy |
| Recommendation rate | Answers recommending the brand as suitable / scorable answers | Requires a suitability rubric |
| Prompt coverage | Questions with a qualifying observation / tested questions | Depends on repetition plan |
| Mention-incidence share | Brand answer-incidences / all tracked brands' answer-incidences | Fix the tracked competitor set |
| Confirmed error frequency | Answers containing at least one confirmed factual error / answers eligible for factual review | Specify reviewed scope; unknown is not false |

Every report should identify the question-set version, cohort, platform or surface, collection period, denominator, annotation version, and missing-data counts.

Do not combine branded and unbranded cohorts without displaying them separately. Do not interpret repeated answers as independent buyers.
